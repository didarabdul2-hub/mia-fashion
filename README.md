# Mia Fashion + Decap CMS

## Admin Dashboard
After deploying on Netlify and enabling Identity + Git Gateway, open:

/admin

From there you can add, edit, or delete product name, price, and image without touching code.

## Important Netlify Setup
1. Deploy this folder to Netlify.
2. Netlify Dashboard > Site configuration > Identity > Enable Identity.
3. Services > Git Gateway > Enable Git Gateway.
4. Invite your email as admin.
5. Visit yoursite.netlify.app/admin.
